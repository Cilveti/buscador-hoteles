Valora seis dimensiones independientes, cada una con un entero entre 0 y 10; usa null si falta evidencia:
1. functionality: cumple los requisitos, incluidos errores y casos límite, sin inventar alcance.
2. codeQuality: código claro, simple, tipado, con responsabilidades y dependencias adecuadas; sin casts para ocultar problemas ni abstracciones vacías.
3. testQuality: tests con sentido que cubren comportamiento real según hoteles-testing. Expectativas independientes de la implementación, casos límite útiles, dobles en fronteras justificadas. Detecta tests tautológicos, assertions débiles, mocks del propio objeto probado, borrados que esconden regresiones y cobertura de relleno. Más tests no implica más calidad.
4. projectGuidelines: sigue las directrices aplicables de las skills y del proyecto. Invocar una skill no prueba cumplirla y no invocarla no merece penalización automática.
5. verificationProcess: ejecuta las comprobaciones pertinentes, aprovecha el feedback, corrige y verifica después de editar. Distingue verify, tests parciales y exploración real de la app. La telemetría tiene limitaciones: ausencia de un evento no prueba ausencia de toda acción.
6. reportAccuracy: el informe final coincide con las ejecuciones observadas y declara pendientes/fallos con precisión. Los checks externos no acreditan ejecuciones del candidato.

Escala: 0 no resuelve la dimensión; 2 presenta carencias graves; 5 resuelve parcialmente con carencias relevantes; 8 es sólido con carencias menores; 10 cumple de forma excelente según la evidencia. Utiliza también valores intermedios justificados. No fabriques hallazgos. Cada nota necesita explicación y referencias concretas a archivos/símbolos/tests/eventos. Distingue fallos que ya existían en baseline, nuevos fallos, fallos de infraestructura y tareas aún no implementadas. Pasar checks no acredita corrección exhaustiva; un check no ejecutado nunca es verde. Las diferencias de tests/configuración merecen revisión, no rechazo automático. Los tests de referencia se preservan externamente aunque estén visibles.
